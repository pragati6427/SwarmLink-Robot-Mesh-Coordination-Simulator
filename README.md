 # SwarmLink-Robot-Mesh-Coordination-Simulator
SwarmLink is a real-time browser simulation of multi-robot coordination using a decentralized Bluetooth mesh network. It visualizes how independent robots communicate, form dynamic connections, and execute coordinated behaviors like exploration, formation control, and collision avoidance.
